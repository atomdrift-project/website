We are putting out [hood](/hood/), quietly, as an experiment.

hood is a supply-chain firewall. It sits between your fetching tools and the
network and looks at what comes back before you get to run it. A public
package, a private package, a tarball behind `curl` — all the same to hood:
unfamiliar bytes, inspected on your machine and handed to the tool only if
they check out.

The short version:

- **Nothing changes.** You still type `npm ci` and `pip install`. hood
  installs shims for the fetching tools on your `PATH` and stays out of the
  way of local work like `go test` and `cargo build`.
- **Nothing leaves.** Unknown artifacts are decomposed by
  [cleave](/cleave/) and classified by [Atomdrift Scan](/scan/), on your
  machine. No cloud scanner, no API key, no telemetry, no private package
  sent to a third party.
- **It judges behavior, not names.** Because it scores what an artifact
  *does*, it can flag a previously unseen 0-day supply-chain attack instead
  of waiting for a feed to name it. Like [isomer](/isomer/), it is an
  application of the same local detection stack.
- **In doubt, it stops.** A fetch fails closed if scanning cannot start.

The [coverage table](/hood/#coverage) on the project page compares hood with
a few related tools, tool by tool.

An early build is on GitHub at
[atomdrift-project/hood](https://github.com/atomdrift-project/hood).

::: note This is an experiment
Verdicts, flags, and output will change without notice, and there is no
stable release. Try it, break it, tell us what you find — but do not put it
anywhere you cannot take it out again. It may eat your cat.
:::
