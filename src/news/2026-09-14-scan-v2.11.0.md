---
title: "Scan v2.11.0: fonts, media files, and fewer dependency guesses"
date: 2026-09-14
summary: "Scan now analyzes fonts and media files, resolves dependencies through lockfiles and registry metadata instead of guessing, and tells you when analysis came up short."
---

This release is about coverage and honesty. Fonts and media files were a blind
spot — a WOFF or an MP4 with a payload stapled to the end sailed right through —
so they now get real analyzers. Dependency resolution leans on lockfiles and
registry metadata instead of reading manifests and hoping. And when analysis
can't finish, the report says so instead of quietly looking clean.

- **[Scan](/scan/)** reconciles Go dependency edges through module and
  workspace context, and refines Cargo and Python manifests against
  co-located lockfiles and registry metadata.
- The fetch worklist is ordered by execution priority: build dependencies and
  proc-macros first, dev dependencies last.
- References carrying a version requirement are no longer superseded by
  another package's pin.
- **[cleave](/cleave/) v2.11.0** gains a font analyzer (sfnt, WOFF, WOFF2,
  EOT) and a media analyzer (WAV, AIFF, MP3, MP4, ICO, GIF, BMP, WebP). SVG is
  now its own rule type.
- A new `analysis_gaps` field reports incomplete analysis in text and JSON,
  independently of findings, and members with gaps stay in compact output.
- Hostile composites now need two notable-or-higher legs instead of one, and
  `downgrade:` gained a scope so one archive member can't silence a rule in
  another.
- JAR class triage ranks classes by constant-pool salience rather than
  attacker-controlled archive order.
- **[filefacts](/filefacts/) v1.7.0** adds ELF anomaly metrics from the Trusting Trust
  paper (entry redirection, section overlap, sections past EOF), x86-64
  direct-syscall site extraction, and Go and Cargo dependency context.
- **[stng](/stng/) v1.12.0** parses JVM class files via the constant pool
  instead of mistaking them for fat Mach-O — they share the `CAFEBABE` magic,
  and the mistake returned no strings at all.
- **fletch v1.3.0** actually verifies Go `h1:` module-tree hashes, and resolves
  Cargo and Python version requirements against registry metadata.
- Cache sweeps in stng, filefacts and fletch gained an entry ceiling and
  least-recently-used eviction, and an interrupted sweep retries within the
  hour instead of booking a full day.
