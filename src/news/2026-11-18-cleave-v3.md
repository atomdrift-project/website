title: "Cleave v3: faster static analysis"
date: 2026-11-18
summary: "Faster binary reverse-engineering via binforms"
---

After weeks of preparation, Cleave v3 is now available! The biggest change is that we've removed the dependency on the rizin program for binary reverse-engineering support, and instead have brought the features we needed into native rust via the [binform](https://github.com/atomdrift-project/binform) project.

Security changes:

- Removed obsolete --extract-dir flag which had a path traversal flaw: [GHSA-rjq9-6g6p-98qr](https://github.com/atomdrift-project/cleave/security/advisories/GHSA-rjq9-6g6p-98qr) - Thanks to @ajayk for the report!
- Precompiled YARA files are no longer trusted; but are instead compiled locally.

Feature changes:

- Index-mode output is now the default (--annotate mode is still supported)
- Removed the obsolete server mode - this feature lives in on it the **scan** and **postdoc** projects.
- Support for unpacking more file formats, like Pyarmor, Nuitka, RC4 PE payloads, Javascript obfuscation, Ren'Py
- New JSON output format (v9)

Optimizations:

- Binary reverse-engineering support moved from rizin to binform; resulting in a ~4X improvement in wall-clock time
- Various AST, regex, scheduling improvements


To install or upgrade on macOS, Linux, FreeBSD, or whatever UNIX flavor:

```shell
curl -fsSL https://install.atomdrift.org/cleave.sh | sh
```

We've also just added a Windows installer:

```shell
irm https://install.atomdrift.org/cleave.ps1 | iex
```
